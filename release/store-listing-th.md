## คำอธิบายสั้น

เชื่อมต่อ Antigravity บนคอมพิวเตอร์ ติดตามงานและส่งคำสั่งจากมือถือ

## คำอธิบายแบบเต็ม

Antigravity Remote ช่วยให้คุณเปิดหน้า Remote ของ Antigravity บนคอมพิวเตอร์ผ่านมือถือ Android และติดตามงานได้สะดวกขึ้น

• เชื่อมต่อผ่าน QR Code หรือลิงก์ Remote ที่คุณเลือก
• จดจำลิงก์ล่าสุดเพื่อกลับมาเชื่อมต่อได้สะดวก
• เปิดหน้า Remote และโต้ตอบกับงานผ่านหน้าจอมือถือ
• เลือกไฟล์หรือรูปภาพแนบผ่านตัวเลือกไฟล์ของ Android เมื่อหน้า Remote รองรับ
• อ่านข้อความออกเสียงด้วยระบบ Text-to-Speech ของเครื่อง

ก่อนเริ่มใช้งาน ต้องมีคอมพิวเตอร์ที่เปิด Antigravity และมีลิงก์ Remote ที่เข้าถึงได้ ฟังก์ชันที่ใช้งานได้ขึ้นอยู่กับหน้า Remote สิทธิ์บัญชี และการเชื่อมต่อเครือข่ายของคุณ

แอปนี้เป็นเครื่องมือจากนักพัฒนาอิสระ ไม่ใช่แอปอย่างเป็นทางการของ Google และไม่ได้รับการรับรองจาก Google ชื่อผลิตภัณฑ์และเครื่องหมายการค้าเป็นของเจ้าของแต่ละราย
