นโยบายความเป็นส่วนตัว (Privacy Policy)

ปรับปรุงล่าสุดเมื่อ: 17 กันยายน 2026 | ผู้พัฒนา: Kunxxs Labs

ยินดีต้อนรับสู่ Antigravity Remote เราเคารพและให้ความสำคัญกับความเป็นส่วนตัวของคุณ นโยบายนี้อธิบายถึงวิธีที่แอปพลิเคชันจัดการและปกป้องข้อมูลของคุณเมื่อใช้งานแอปพลิเคชัน

1. การเชื่อมต่อและข้อมูลการใช้งาน (Connection & Remote Content)

Antigravity Remote ทำหน้าที่เป็นเครื่องมือแสดงผลและควบคุมระยะไกล (Client Interface) เชื่อมต่อไปยังโปรแกรม Google Antigravity บนเครื่องคอมพิวเตอร์ของคุณ:

  • URL หรือ QR Code เชื่อมต่อ: แอปจะบันทึก URL ล่าสุดที่คุณเลือกเชื่อมต่อไว้ในหน่วยความจำของอุปกรณ์ (Private Local Storage) เพื่อความสะดวกในการเชื่อมต่อครั้งถัดไป โดยไม่มีการส่งข้อมูลนี้ไปยังเซิร์ฟเวอร์ภายนอก
  • ข้อมูลคำสั่งและข้อความแชท: คำสั่ง ข้อความ หรือรูปภาพที่คุณส่ง จะถูกส่งตรงไปยังเซสชันของโปรแกรมบนเครื่องคอมพิวเตอร์ของคุณผ่านระบบ Secure Tunnel ที่จัดเตรียมโดย Google Antigravity
  • คุกกี้และแคช (Cookies & Cache): ตัวแสดงผลเว็บ (WebView) อาจจัดเก็บแคชและคุกกี้บนอุปกรณ์ของคุณ เพื่อให้สามารถเปิดอ่านประวัติการสนทนาในโหมดออฟไลน์ได้

2. สิทธิ์การเข้าถึงอุปกรณ์ (Device Permissions)

  • กล้องถ่ายภาพ (Camera): ใช้เฉพาะเมื่อคุณกดปุ่มสแกน QR Code เพื่อเชื่อมต่อกับคอมพิวเตอร์ ระบบจะประมวลผลภาพ QR Code บนตัวเครื่องโดยตรง และไม่มีการบันทึกหรืออัปโหลดภาพจากกล้องออกไปภายนอก
  • การเลือกไฟล์และรูปภาพ (Files & Photos): ใช้ระบบเลือกไฟล์มาตรฐานของ Android (System File Picker) เพื่อให้คุณเลือกรูปภาพหรือไฟล์ที่ต้องการส่งให้ AI บนคอมพิวเตอร์วิเคราะห์ โดยแอปไม่มีการขอสิทธิ์เข้าถึงคลังภาพทั้งหมด
  • คลิปบอร์ด (Clipboard): ใช้เมื่อคุณแตะปุ่ม "วางลิงก์ที่คัดลอกมา" เพื่ออ่าน URL การเชื่อมต่อที่คัดลอกมาจากคอมพิวเตอร์
  • ระบบแปลงข้อความเป็นเสียง (Text-to-Speech): ใช้ระบบ TTS ของตัวเครื่อง Android เพื่ออ่านข้อความสรุปจาก AI ให้คุณฟังผ่านลำโพง

3. การจัดเก็บและการลบข้อมูล (Data Storage & Deletion)

ข้อมูลการเชื่อมต่อและแคชจะถูกบันทึกไว้ในอุปกรณ์ของคุณเท่านั้น คุณสามารถลบข้อมูลทั้งหมดได้ตลอดเวลาโดยการไปที่ การตั้งค่าของ Android > แอปพลิเคชัน > Antigravity Remote > ล้างข้อมูล (Clear Data) หรือถอนการติดตั้งแอป

4. โฆษณาและการวิเคราะห์ (Advertising & Analytics)

แอปพลิเคชันนี้ ไม่มีการติดตั้ง SDK โฆษณา (No Ads) และ ไม่มีการเก็บสถิติการใช้งานส่วนบุคคล (No Tracking/Analytics SDK) ใดๆ ทั้งสิ้น
